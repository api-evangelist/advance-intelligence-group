# Advance Intelligence Group — ADVANCE.AI Open API

> Advance Intelligence Group is a Singapore-headquartered AI technology company (founded 2016, backed by SoftBank Vision Fund and Warburg Pincus). Its ADVANCE.AI business unit provides digital identity verification, KYC/KYB, AML and risk-management services via a public eKYC Open API: token authentication, document verification, identity-document OCR, face comparison and liveness detection. Requests authenticate with a signature-issued access token passed in the X-ACCESS-TOKEN header and share a common response envelope (code / message / data / transactionId / pricingStrategy).

## APIs
- [ADVANCE.AI Open API docs](https://doc.advance.ai/): eKYC building blocks — auth, document verification, OCR, face, liveness.
- Base URL: https://api.advance.ai (Singapore regional host: https://sg-api.advance.ai)

## Operations
- generateToken — POST /openapi/auth/ticket/v1/generate-token
- getDocumentVerificationAuthLicense — POST /intl/openapi/face-identity/document-verification/v1/auth-license
- queryDocumentVerification — POST /intl/openapi/face-identity/document-verification/v1/query
- ocrKtpCheck — POST /openapi/face-recognition/v3/ocr-ktp-check
- faceComparison — POST /openapi/face-recognition/v4/check
